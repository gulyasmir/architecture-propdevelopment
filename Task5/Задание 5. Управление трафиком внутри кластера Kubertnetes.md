# Задание 5. Управление трафиком внутри кластера Kubertnetes


1. #### Развёртывание сервисов в Kubernetes.

   Создаем **4 пода с метками**:

```
kubectl run front-end-app --image=nginx --labels role=front-end --expose --port 80
kubectl run back-end-api-app --image=nginx --labels role=back-end-api --expose --port 80
kubectl run admin-front-end-app --image=nginx --labels role=admin-front-end --expose --port 80
kubectl run admin-back-end-api-app --image=nginx --labels role=admin-back-end-api --expose --port 80
```

#### 2. Создание сетевой политики (non-admin-api-allow.yaml)

Эта политика:

* **Разрешает** трафик между `front-end-app` и `back-end-api-app`
* **Разрешает** трафик между `admin-front-end-app` и `admin-back-end-api-app`
* **Блокирует** весь другой трафик

```
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: non-admin-api-allow
  namespace: default
spec:
  podSelector: {}
  policyTypes:
    - Ingress
  ingress:
    - from:
        - podSelector:
            matchLabels:
              role: front-end
      ports:
        - protocol: TCP
          port: 80
    - from:
        - podSelector:
            matchLabels:
              role: admin-front-end
      ports:
        - protocol: TCP
          port: 80
  egress:
    - to:
        - podSelector:
            matchLabels:
              role: back-end-api
      ports:
        - protocol: TCP
          port: 80
    - to:
        - podSelector:
            matchLabels:
              role: admin-back-end-api
      ports:
        - protocol: TCP
          port: 80

```

#### 3. Применение сетевой политики

```
kubectl apply -f non-admin-api-allow.yaml
```

#### **4. Проверка работы сетевых политик**

Запускаем тестовый контейнер и проверяем соединение с сервисами:

```
kubectl run test-$RANDOM --rm -i -t --image=alpine -- sh
```

Проверяем доступность `admin-back-end-api` для `admin-front-end`

```
wget -qO- --timeout=2 http://back-end-api-app
```

Попытка соединиться с запрещёнными сервисами

```
wget -qO- --timeout=2 http://front-end-app   # Должен быть отказ
wget -qO- --timeout=2 http://admin-front-end-app  # Должен быть отказ
```

#### Результат.

* **Сетевой трафик между UI и API разрешён** (front-end ↔ back-end-api, admin-front-end ↔ admin-back-end-api).
* **Доступ к другим сервисам заблокирован**.
* **Политика применена и протестирована**.
